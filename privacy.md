# Privacy Policy (rclone-vault)

This application is a personal-use tool operated by a single individual. It is not offered to any other users.

It accesses only the owner's own Google Drive folder, in order to sync it with the owner's own devices and server. The data is stored only on the owner's own devices and server. It is not shared with, sold to, or transferred to any third party. No analytics or advertising data is collected.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

# プライバシーポリシー

このアプリは、1人の利用者が個人で使うためのツールです。他のユーザーには提供していません。

所有者本人の Google ドライブのフォルダにだけアクセスし、所有者本人の端末とサーバーと同期します。データは、所有者本人の端末とサーバーにだけ保存します。第三者への提供、販売、共有は行いません。分析や広告のためのデータ収集は行っていません。

Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。
